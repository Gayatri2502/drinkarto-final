# Public image sources and attribution

Drinkarto uses licensed editorial photographs for place and production context and Wikimedia Commons bottle photographs for representative category examples. Credits and license links are rendered beside each image. Product workbook records do not have verified SKU-level packaging, so a category photo must not be presented as a match for the named item.
