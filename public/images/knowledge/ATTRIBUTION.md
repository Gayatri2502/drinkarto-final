# Drinkarto photography: source and reuse terms

Photographs are stored as web-sized source files and displayed in responsive frames. Each displayed photograph includes visible author/source and license links. Captions describe the photographed scene so an editorial image is not mistaken for an exact brand, product, or style. Image resizing and responsive framing are the only delivery changes; the files remain available under the licenses listed below. Where a license requires share-alike terms, the corresponding image is distributed under that same license.
